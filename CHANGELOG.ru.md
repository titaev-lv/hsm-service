# Changelog 

## v1.1.1 - 2026-02-08

### Исправления безопасности
- Исправлена утечка PIN в логах команды ротации (маскирование чувствительных данных)
- Предотвращена инъекция команд в команде rotate (G204/CWE-78)
- Добавлена валидация путей для предотвращения атак directory traversal (G304/CWE-22)
- Ограничены права доступа к файлам метаданных до 0600 (G302/G306/CWE-276)
- Добавлена обработка необработанных ошибок (G104/CWE-703)
- Добавлены явные проверки переполнения с аннотациями nosec (G115/CWE-190)

### Новые возможности
- Добавлено автоматическое обновление контрольных сумм после ротации ключей
- Реализован формат временных меток RFC3339Micro для консистентной сериализации YAML

### Исправления ошибок
- Сохранение inode при сохранении файлов метаданных (совместимость с bind mount)
- Исправлены пути PKI в config.yaml для корректной валидации сертификатов
- Исправлена надёжность теста отзыва сертификатов

### Тестирование
- Добавлены unit-тесты для validateFilePath с защитой от directory traversal
- Улучшена изоляция интеграционных тестов с выделенными контейнерами
- Добавлен полнофункциональный тест отзыва сертификатов
- Автоматическая генерация PKI для самодостаточных интеграционных тестов

### Документация
- Обновлён формат временных меток на RFC3339Micro во всей документации
- Добавлены отсутствующие примеры параметра rotation_interval_days

## v1.1.0

### Новые возможности
- **Автоматизированная инициализация PKI и Docker**: Добавлен скрипт `init-pki-docker.sh` для одноэтапной инициализации
  - Автоматически генерирует Root CA и все сертификаты (сервера + клиентов)
  - Создаёт конфигурацию metadata.yaml
  - Собирает и запускает Docker контейнер
  - Проверяет здоровье сервиса
  - Поддерживает опции `--force` и `--skip-docker`

### Документация
- Улучшена QUICKSTART_DOCKER.md:
  - ⚡ Раздел быстрого старта с одной командой
  - 📖 Пошаговая инструкция ручной настройки
  - 💡 Справочник полезных команд
  - ❓ Секция решения проблем
- Добавлена VERSIONING.md с детальной стратегией версионирования

### Инфраструктура
- Исправлено монтирование metadata.yaml (возврат к стратегии mount из docker-compose.yml)
- Улучшены пути к сертификатам
- Добавлена поддержка файла VERSION для Docker build

### Исправления ошибок
- Исправлено обращение с metadata.yaml в docker-compose.yml
- Исправлена логика metadata.yaml в Dockerfile
- Исправлены пути к сертификатам в конфигурации

## v1.0.1

### Основное 
- Базовый сервис HSM и интеграция PKCS#11/SoftHSM.
- CLI инструменты: hsm-admin, create-kek.
- Скрипты ротации ключей, hot‑reload KEK.

### Security & Compliance
- Исправления OWASP Top 10 (A02/A03/A04/A05/A08/A09).
- Лимиты размеров запросов, таймауты, rate limiting.
- Улучшение логирования/мониторинга, ротация логов, Prometheus‑метрики.
- Валидация AAD и проверка целостности KEK.

### Инфраструктура и деплой
- Docker/Docker Compose.
- PKI bootstrap и инструкции.
- Скрипты init/rotation/backup/restore, проверки целостности.

### Тестирование и качество
- Unit/integration/e2e/performance/security/compliance тесты.
- Нагрузочные, стресс‑ и extreme‑тесты.
- Оптимизация HTTP/2 и сетевого стека.

### Документация
- Руководства quickstart/production/security audit.
- Инструкции восстановления, мониторинга, firewall/SELinux/AppArmor.
